# Downthread website

The public homepage and privacy policy for Downthread, a browser extension that exports a post's comments and replies to CSV or JSON.

- Homepage: https://grim-reaper-bit.github.io/downthread/
- Privacy policy: https://grim-reaper-bit.github.io/downthread/privacy.html
- Chrome Web Store: https://chromewebstore.google.com/detail/bbjhkmainlkhbjobciniddmndbjagfmn
- Support: downthread.support@gmail.com

This repository contains only the website. The extension itself is distributed through the Chrome Web Store.
