Get a YouTube API key for Downthread

Downthread exports YouTube comments through Google's official YouTube Data API, and the API needs a key. You create the key in your own Google Cloud project, so every request Downthread makes counts against your project's quota, not anyone else's. Facebook, TikTok, Instagram and X need no key.

Looking up the video costs one quota unit. Each page of comment threads or replies also costs one unit, and Downthread requests up to 100 items per page. A project's default allocation is 10,000 units a day; see Google's quota costs (opens in a new tab).

YouTube Data API overview (opens in a new tab)
  • A Google account
  • Downthread installed in Chrome
  • A public YouTube video with comments
  1. 1

    Sign in and choose a project

    Sign in to Google Cloud Console with your Google account. In the project picker at the top of the page, select an existing project or choose New project and create one. Any name works; for example, Downthread YouTube.

    Keep this project selected for every step that follows.

    Open Google Cloud Console (opens in a new tab)
  2. 2

    Enable YouTube Data API v3

    With that project selected, open the YouTube Data API v3 page and click Enable. If the button says Manage instead, the API is already enabled for this project and you can go on.

    Open YouTube Data API v3 (opens in a new tab)
  3. 3

    Create an API key

    In the same project, open APIs & Services → Credentials, then choose Create credentials → API key.

    Downthread uses a standard API key, which is all that reading public comments needs. You do not need an OAuth client or a service account.

    Create a new key just for Downthread, even if the project already has one. Its restrictions can then be set for Downthread without changing a key another application relies on.

    Open Credentials (opens in a new tab)
  4. 4

    Restrict the key to YouTube, then copy it

    Under API restrictions, select Restrict key and choose YouTube Data API v3. Complete the creation, save the restriction, and copy the key string. If Google shows you the key before you have set the restriction, open the key from the Credentials list to find API restrictions, then save.

    Restricting the key means that, if it ever leaked, it could only be used for the YouTube Data API.

    Application restrictions. Google recommends restricting a key both by API and by where it is used, where the two are compatible. Downthread calls Google from the extension's background worker, not from a website, and we have not verified an application restriction that works with it. If you are unsure, leave Application restrictions at None and keep the API restriction above. If you set one and the panel reports a restriction error, see Key rejected or restricted.

    Google's API key instructions (opens in a new tab)
  5. 5

    Paste the key into the Downthread panel

    Open a public YouTube video with comments enabled. Once its comments load, Downthread appears minimized at the top right of the page; click it to open the panel. You can also click the Downthread icon in Chrome's toolbar and choose Open exporter panel.

    Paste the key into the YouTube Data API key field and click Save key.

    The key is stored in the extension's local browser storage, on this computer only, and is sent only to Google with each request.

    Paste your key only into the Downthread panel. This page gives instructions; it never asks for your key and has nowhere to put it.

  6. 6

    Export, and confirm the key works

    Choose CSV or JSON, then click Export comments.

    “Key saved.” confirms the key is stored in this browser. It does not yet mean Google accepted it. The first sign of that is the line at the top of the panel, which looks the video up and shows its title and comment count. A successful export, saved to your Downloads folder, confirms the key works.

    To replace the key later, look under Export comments: the line API key saved. has a Change link beside it. Click it, paste the new key and click Save key again.

Troubleshooting

If the export doesn't start.

The panel says what went wrong in plain words. Find its message below and do the one thing listed.

API not enabled

The YouTube Data API v3 is not enabled for this key's Google Cloud project.

Do this In the project picker, select the project you created the key in, open YouTube Data API v3 (opens in a new tab), click Enable, then wait a few minutes and export again.

Key rejected or restricted

The YouTube API key was rejected. …

Do this Check the key itself first. In Credentials (opens in a new tab), with the key's project selected, confirm the key is listed, copy the whole string again, then click Change in the panel and paste it. If the key is gone or has expired, create a new one (step 3).

YouTube refused this request under the API key's restrictions. …

Do this Leave that key as it is, since another application may rely on its restrictions. In the same project, create a new key just for Downthread (step 3), restrict it to YouTube Data API v3 with no application restriction (step 4), then click Change in the panel and paste the new key. We have not verified an application restriction that works with the extension.

Quota exceeded

The daily YouTube API quota is used up. It resets at midnight Pacific time.

Do this Export again after midnight Pacific time. Comments captured before the limit are already saved, marked partial, and Recent exports in the panel can download them again without using quota.

Comments disabled on the video

Comments are turned off on this video.

Do this Open a different video whose comments you can see below it, and export there. A livestream has live chat instead of comments, and live chat is not part of an export.

Still stuck? Copy the panel's message and email downthread.support@gmail.com. Never include your API key.
